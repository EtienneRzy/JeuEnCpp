Pour GIT :

-> Authentification
git config --global user.name "TonNom"
git config --global user.email "ton.email@example.com"

-> Clé SSH (à ajouter sur github ensuite)
ssh-keygen -t ed25519 -C "email@example.com"

-> Clone projet avec SSH
git clone git@github.com:NomGitHub/JeuEnCpp.git

-> Créer branche
git checkout NomBranche
git branch NomBranche

-> Push branche
git add .
git commit -m "kjhkjhkjhkj"
git push

-> Mettre à jour main
git checkout main
git pull
